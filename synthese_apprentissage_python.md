# Synthèse des apprentissages Python (débutant)

## Installation et environnement
- Python est installé et reconnu par VS Code.
- VS Code est installé avec l'extension Python.
- Un fichier Python doit se terminer par `.py` pour être reconnu comme programme Python.
- Le terminal permet d'exécuter des commandes et des programmes Python.

## Notions apprises

### Affichage
```python
print("Bonjour")
```
Affiche du texte dans le terminal.

### Variables
```python
prenom = "scmonarch"
age = 25
```
Une variable est une boîte qui stocke une valeur.

### Types de données de base

Texte :
```python
prenom = "scmonarch"
```

Nombre :
```python
age = 25
```

Booléen :
```python
est_etudiant = True
est_etudiant = False
```

### Afficher une variable
```python
prenom = "scmonarch"
print(prenom)
```

### Mélanger texte et variables
```python
print("Nom :", prenom)
print("Âge :", age)
```

## Points importants retenus

- `=` sert à stocker une valeur dans une variable.
- `print()` sert à afficher une valeur.
- `True` et `False` doivent être écrits en anglais avec une majuscule.
- Écrire du code ne l'exécute pas automatiquement.
- Il faut enregistrer puis exécuter le fichier.
- Un fichier sans extension `.py` n'est pas reconnu comme un programme Python.
- Le terminal affiche les résultats et les erreurs.

## Git (bases rencontrées)

Configuration de l'identité Git :

```bash
git config --global user.name "Nom"
git config --global user.email "email@example.com"
```

Ajouter des fichiers :

```bash
git add .
```

Créer un commit :

```bash
git commit -m "message"
```

Envoyer vers GitHub :

```bash
git push
```
